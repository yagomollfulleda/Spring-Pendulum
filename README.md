# Lagrangian Modelling and Numerical Analysis of a Spring Pendulum

## Overview

This project investigates the dynamics of a spring pendulum using analytical and numerical methods.

## Methods

- Lagrangian mechanics.
- Matrix diagonalisation.
- Numerical simulations.
- Newton–Raphson method.

## Repository structure

- spring_pendulum_report.pdf: Full project report (written in Spanish).
- `code/`: MATLAB source files.
